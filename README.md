## expats-native

React Native (Expo) client for **Expats**, a dating app for expatriates. It runs
against the existing `primi-signals` Firebase project — Firestore collections,
Cloud Functions, and seed profiles are already live, so the app is a client-only
build.

See [`expats-native/README.md`](expats-native/README.md) for setup, the backend
contract, and how to make a development build.

```bash
cd expats-native
npm install
cp .env.example .env
npm start
```
